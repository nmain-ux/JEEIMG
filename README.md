# JEE question figures

Every figure referenced by the JEE bank behind [pyqbox.com](https://pyqbox.com),
as WebP — 6,162 files, the same images the Android app bundles.

Served to the website over jsDelivr rather than from here directly:

```
https://cdn.jsdelivr.net/gh/nmain-ux/JEEIMG@main/<filename>
```

Filenames are what the question bank's `[IMG:…]` markers name, so nothing here
can be renamed without breaking a page. Replaces `nmain-ux/JEE-images`, which
held the same pictures as PNG and JPG at roughly three times the bytes.
